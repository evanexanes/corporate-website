# Corporate website

A four-page company site (Home, About, Services, Contact) with placeholder content. A self-initiated WordPress practice build by Evan Exanes.

- **Live demo:** https://evanexanes.github.io/corporate-website/
- **Case study:** https://evanexanes.github.io/02-case-study-corporate.html
- **Stack:** WordPress · Elementor · OceanWP · Contact Form 7

## What this repository is

A static copy of the WordPress site, exported with Simply Static so it can run on GitHub Pages.
It is generated HTML, CSS and JavaScript, not the WordPress source: there is no PHP, database or
`wp-config.php` here.

GitHub Pages cannot run PHP, so anything that needs the WordPress server does not work in this copy.
The contact form sends through Web3Forms instead of Contact Form 7.
